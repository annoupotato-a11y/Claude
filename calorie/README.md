# カロリー手帳

食事の写真を撮ると、Claude が料理を見分けて **カロリーと PFC（たんぱく質・脂質・炭水化物）** を推定し、
1日ごとに記録していくWebアプリです。ビルドもインストールも不要です。

## 使い方

1. 「写真を撮る」（スマホではカメラが開きます）か「写真を選ぶ」を押す
2. 数十秒で品目ごとの推定値が **栄養成分表示** の形で出ます
   - 量や品目が違っていたら、その場で数値を直せます
   - 「補足」に「ご飯は半分」「ドレッシングなし」などと書いて「もう一度解析」もできます
3. 朝食／昼食／夕食／間食（時刻から自動で選ばれます）を確かめて「記録する」

**商品をそのまま食べたとき**は、「商品をそのまま食べたとき」の欄に商品名（例：`セブン ツナマヨおにぎり 2個`）を入れて
「記録」を押すだけで記録されます。Claude がパッケージの栄養成分表示の値（分からなければ似た商品からの推定値）を調べます。
一度記録した商品は候補に出て、次からは前回の値ですぐ記録されます。推定に自信がないときだけ、記録前に確認画面が開きます。

写真がないときは「手で入力」で記録できます。記録したカードを押すと、あとから直したり削除したりできます。

| 画面 | できること |
| --- | --- |
| 記録 | 1日の合計（目標に対するリング）、あと何kcal食べられるか、PFC の目安との比較、食事ごとの一覧。日付を戻って過去の日も記録できます |
| 推移 | 直近7日の棒グラフ（目標の破線つき）と日ごとの表。棒を押すとその日を開きます。期間（直近7日／30日／すべて）を選んで **Excel（.xlsx）に書き出せます**（「日別」と「食事の明細」の2シート） |
| 設定 | 1日の目標kcal（年齢・身長・体重・活動量から目安を計算できます）、API キー、バックアップの書き出し／読み込み |

PFC の目安は目標kcalのエネルギー比 15% / 25% / 60% から計算しています。
推定値は写真からの見積もりなので、正確な管理が必要な場合は量を確かめて修正してください。

## 写真の解析について

解析には次のどちらかが必要です。

- **claude.ai の Artifact として開く** … 開いている人の Claude アカウントで解析します。キーは不要です。
  初回の解析時に「Claude を使う／画像を送る」許可を求められます。
- **Anthropic API キーを入れる** … `index.html` や `standalone.html` を直接開くときは、「設定」に
  API キー（`sk-ant-…`）を入れてください。キーはその端末のブラウザにだけ保存され、
  解析時に `api.anthropic.com` へ直接送られます（モデルは `claude-opus-5-5`）。

## 開き方

```
open calorie/index.html             # パソコンでそのまま
node tools/build-standalone.mjs --app calorie   # 1ファイル版 calorie/standalone.html を作り直す
```

スマホでは、GitHub Pages などで `calorie/` を公開して開き、「ホーム画面に追加」するとアプリとして使えます
（`sw.js` が本体をキャッシュするので、記録の閲覧・手入力は圏外でもできます）。

## データの保存場所

ふだんはブラウザの `localStorage`（キー `calorie-note/meals/v1`）に保存されます。写真は 240px の小さなサムネイルだけを残します。
claude.ai の Artifact として開いたときは、その人専用の保存領域（`data/users/<id>/`、本人以外は読めません）にも保存され、
端末をまたいで同じ記録が見られます（画面上部に「☁ 同期中」と出ます）。API キーはクラウドには保存しません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `assets/style.css` / `assets/app.js` | アプリ本体 |
| （外部）SheetJS 0.18.5 | Excel 書き出し。押したときだけ cdnjs から読み込むので、書き出しには通信が必要です |
| `manifest.webmanifest` / `sw.js` / `assets/icon.svg` | ホーム画面に追加・オフライン対応 |
| `standalone.html` | 上記をまとめた1ファイル版（生成物） |
