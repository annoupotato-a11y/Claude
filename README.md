# 言語化ノート

書籍『言語化ノート術』のフォーマット（**メモ（WHAT）＋のはなぜか？ → 理由（WHY） → 結論 → メモ欄**）を、
毎日書き留めていくためのシンプルなWebアプリです。

<pre>
┌──────────────────────────────┐
│ メモ（WHAT）＋のはなぜか？   │
│ 理由（WHY）                  │
│ 結論                         │
│ メモ欄（自由にアレンジ）     │
└──────────────────────────────┘
</pre>

## 使い方

`index.html` をブラウザで開くだけです。ビルドもインストールも不要です。

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

スマートフォンで使う場合は、この3ファイル（`index.html` / `assets/style.css` / `assets/app.js`）を
任意の静的ホスティング（GitHub Pages など）に置き、ホーム画面に追加すると日課にしやすくなります。

## できること

| 機能 | 説明 |
| --- | --- |
| 日付ごとの記録 | 日付を選んで1日1件でも複数件でも保存できます |
| 4項目フォーマット | 書籍のフォーマットをそのまま画面化しています |
| 下書きの自動保存 | 書きかけで閉じても、次に開いたときに復元します |
| 一覧・検索 | 過去のノートを新しい順に表示、本文と日付を全文検索できます |
| 編集・削除 | 一覧のカードをクリックすると編集画面に戻ります |
| 連続記録日数 | 何日続いているかを画面上部に表示します |
| バックアップ / 読み込み | JSONで書き出し・取り込み（重複IDは新IDを振って追記） |
| Markdown書き出し | 全ノートを1つの `.md` にまとめて出力します |

キーボードショートカット: `Ctrl`（macOSは `⌘`）+ `Enter` で保存。

## 書き方のコツ

1. **メモ（WHAT）** — 出来事や感じたことを一文で。読み終えたときに「〜のはなぜか？」と続く問いになるように書きます。
2. **理由（WHY）** — その問いへの答えを、事実・背景・感情に分けて掘り下げます。
3. **結論** — 「だから何が言えるか」を言い切ります。ここが翌日以降に効く一行になります。
4. **メモ欄** — 引用、キーワード、明日やることなど自由に。

## データの保存場所

すべてブラウザの `localStorage`（キー `gengoka-note/entries/v1`）に保存され、外部には一切送信されません。
ブラウザのデータを消すとノートも消えるため、ときどき「バックアップ」でJSONを書き出しておくことをおすすめします。
