# 言語化ノート

書籍『言語化ノート術』のフォーマット（**メモ（WHAT）＋のはなぜか？ → 理由（WHY） → 結論 → 行動**）を、
毎日書き留めていくためのシンプルなWebアプリです。

書籍の完成例と同じ **見開き** で書きます。

<pre>
      ── 左ページ ──              ── 右ページ ──
 ┌────────────────────┐      ┌────────────────────┐
 │ ┌────────────────┐ │      │ [結論]             │
 │ │ ○○した。      │ │      │ ○○なのは、       │
 │ │   のはなぜか？ │ │      │ △△だから         │
 │ └────────────────┘ │      ├────────────────────┤
 │ 理由（WHY）        │      │ [行動]             │
 │ ・勝ちたかった     │      │ ・明日は○○する   │
 │ ・ほめられた ←塗る │      │ ・△△を調べる     │
 │ ・認められた ←塗る │      │                    │
 └────────────────────┘      └────────────────────┘
</pre>

- **問い**（左上の枠）… メモ（WHAT）を書くと、末尾に「のはなぜか？」が付いて問いになります
- **理由（WHY）**… 箇条書きで並べ、繰り返し出てくる言葉を**マーカー**で塗って共通項を見つけます
- **結論**… マーカーで浮かんだ言葉を使って言い切ります
- **行動**… 見出しは自由に書き換えられます（メモ欄・気づき・明日やること など）

## 使い方（パソコン）

`index.html` をブラウザで開くだけです。ビルドもインストールも不要です。

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## 使い方（スマホ）

### A. GitHub Pages に置いてホーム画面に追加する

リポジトリの Settings → Pages で、このブランチの `/ (root)` を公開先に指定します。
表示された URL をスマホで開き、

- iPhone（Safari）: 共有 → 「ホーム画面に追加」
- Android（Chrome）: メニュー → 「アプリをインストール」

これでアドレスバーのないアプリとして起動し、Service Worker（`sw.js`）が本体をキャッシュするので
電波の届かない場所でも書けます。ノートはその端末のブラウザ内に保存されます。

### B. 1ファイル版を持ち歩く

`standalone.html` は HTML・CSS・JS を1枚にまとめたファイルです。
メールやクラウドストレージで自分に送っておけば、どの端末でもそのファイル単体で動きます。

```
node tools/build-standalone.mjs        # index.html などから standalone.html を作り直す
python3 tools/make-icons.py            # ホーム画面用アイコンを作り直す
```

### スマホでの操作

- 保存バーは画面下に固定されます（`保存する` / `新規` / `印刷 PDF`）
- マーカーは、文字を長押しで選ぶと下に出る **「選んだ言葉にマーカー」** を押します
- 見開きは上下2段（左ページ→右ページの順）に並び替わります

## できること

| 機能 | 説明 |
| --- | --- |
| 日付ごとの記録 | 日付を選んで1日1件でも複数件でも保存できます |
| 見開きフォーマット | 左＝問い＋理由、右＝結論＋行動。書籍の完成例と同じ配置です |
| 箇条書き入力 | `Enter` で次の行、行頭で `Backspace` で前の行と結合、`×` で行を削除 |
| マーカー | 文字を選んで「マーカー」ボタン（または `Ctrl`/`⌘` + `M`）。もう一度押すと消えます |
| 見出しのアレンジ | 右下の「行動」は自由な言葉に書き換えられます |
| タイトル | 見開きの上に「今回の◯◯の事例」のような見出しを付けられます（任意） |
| 印刷 / PDF | 見開きだけをそのまま印刷・PDF保存できます |
| 下書きの自動保存 | 書きかけで閉じても、次に開いたときに復元します |
| 一覧・検索 | 過去のノートを新しい順に表示、本文と日付を全文検索できます |
| 編集・削除 | 一覧のカードをクリックすると編集画面に戻ります |
| 連続記録日数 | 何日続いているかを画面上部に表示します |
| バックアップ / 読み込み | JSONで書き出し・取り込み（重複IDは新IDを振って追記） |
| Markdown書き出し | 全ノートを1つの `.md` にまとめて出力します |

キーボードショートカット: `Ctrl`（macOSは `⌘`）+ `S` または `Enter` で保存、`Ctrl`/`⌘` + `M` でマーカー。

## 書き方のコツ

1. **メモ（WHAT）** — 出来事や感じたことを一文で。「〜のはなぜか？」と続く問いになるように書きます。
2. **理由（WHY）** — 思いつくまま箇条書きで。数が出るほど共通項が見つかります。
3. **マーカー** — 何度も出てくる言葉・引っかかる言葉を塗ります（例：「認められた」「評価」）。
4. **結論** — 塗った言葉をつないで「◯◯なのは、△△だから」と言い切ります。
5. **行動** — 結論から、明日以降に取る具体的な行動を書き出します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `assets/style.css` / `assets/app.js` | アプリ本体 |
| `manifest.webmanifest` / `sw.js` / `assets/icon-*.png` | ホーム画面に追加・オフライン対応 |
| `standalone.html` | 上記をまとめた1ファイル版（生成物） |
| `tools/build-standalone.mjs` / `tools/make-icons.py` | 生成物を作り直すスクリプト |

## データの保存場所

ふだんはブラウザの `localStorage`（キー `gengoka-note/entries/v2`）だけに保存され、外部には送信されません。
ブラウザのデータを消すとノートも消えるため、ときどき「バックアップ」でJSONを書き出しておくことをおすすめします。

Claude の Artifact として公開した場合のみ、保存先が**クラウド（アプリ専用の保存領域）**になり、
端末をまたいで同じノートを読み書きできます（画面右上に「☁ 同期中」と表示されます）。
その場合も端末内に控えを残すので、圏外でも直前の内容を読めます。
