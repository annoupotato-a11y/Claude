# 言語化ノート

書籍『言語化ノート術』のフォーマット（**メモ（WHAT）＋のはなぜか？ → 理由（WHY） → 結論 → 行動**）を、
毎日書き留めていくためのシンプルなWebアプリです。

書籍の完成例と同じ **見開き** で書きます。

<pre>
      ── 左ページ ──              ── 右ページ ──
 ┌────────────────────┐      ┌────────────────────┐
 │ ┌────────────────┐ │      │ [結論]             │
 │ │ ○○した。      │ │      │ ○○なのは、       │
 │ │   のはなぜか？ │ │      │ △△だから         │
 │ └────────────────┘ │      ├────────────────────┤
 │ 理由（WHY）        │      │ [行動]             │
 │ ・勝ちたかった     │      │ ・明日は○○する   │
 │ ・ほめられた ←塗る │      │ ・△△を調べる     │
 │ ・認められた ←塗る │      │                    │
 └────────────────────┘      └────────────────────┘
</pre>

- **問い**（左上の枠）… メモ（WHAT）を書くと、末尾に「のはなぜか？」が付いて問いになります
- **理由（WHY）**… 箇条書きで並べ、繰り返し出てくる言葉を**マーカー**で塗って共通項を見つけます
- **結論**… マーカーで浮かんだ言葉を使って言い切ります
- **行動**… 見出しは自由に書き換えられます（メモ欄・気づき・明日やること など）

## 使い方

`index.html` をブラウザで開くだけです。ビルドもインストールも不要です。

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

スマートフォンで使う場合は、この3ファイル（`index.html` / `assets/style.css` / `assets/app.js`）を
任意の静的ホスティング（GitHub Pages など）に置き、ホーム画面に追加すると日課にしやすくなります。

## できること

| 機能 | 説明 |
| --- | --- |
| 日付ごとの記録 | 日付を選んで1日1件でも複数件でも保存できます |
| 見開きフォーマット | 左＝問い＋理由、右＝結論＋行動。書籍の完成例と同じ配置です |
| 箇条書き入力 | `Enter` で次の行、行頭で `Backspace` で前の行と結合、`×` で行を削除 |
| マーカー | 文字を選んで「マーカー」ボタン（または `Ctrl`/`⌘` + `M`）。もう一度押すと消えます |
| 見出しのアレンジ | 右下の「行動」は自由な言葉に書き換えられます |
| タイトル | 見開きの上に「今回の◯◯の事例」のような見出しを付けられます（任意） |
| 印刷 / PDF | 見開きだけをそのまま印刷・PDF保存できます |
| 下書きの自動保存 | 書きかけで閉じても、次に開いたときに復元します |
| 一覧・検索 | 過去のノートを新しい順に表示、本文と日付を全文検索できます |
| 編集・削除 | 一覧のカードをクリックすると編集画面に戻ります |
| 連続記録日数 | 何日続いているかを画面上部に表示します |
| バックアップ / 読み込み | JSONで書き出し・取り込み（重複IDは新IDを振って追記） |
| Markdown書き出し | 全ノートを1つの `.md` にまとめて出力します |

キーボードショートカット: `Ctrl`（macOSは `⌘`）+ `S` または `Enter` で保存、`Ctrl`/`⌘` + `M` でマーカー。

## 書き方のコツ

1. **メモ（WHAT）** — 出来事や感じたことを一文で。「〜のはなぜか？」と続く問いになるように書きます。
2. **理由（WHY）** — 思いつくまま箇条書きで。数が出るほど共通項が見つかります。
3. **マーカー** — 何度も出てくる言葉・引っかかる言葉を塗ります（例：「認められた」「評価」）。
4. **結論** — 塗った言葉をつないで「◯◯なのは、△△だから」と言い切ります。
5. **行動** — 結論から、明日以降に取る具体的な行動を書き出します。

## データの保存場所

すべてブラウザの `localStorage`（キー `gengoka-note/entries/v2`）に保存され、外部には一切送信されません。
ブラウザのデータを消すとノートも消えるため、ときどき「バックアップ」でJSONを書き出しておくことをおすすめします。
